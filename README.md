# 📜 텍스트 RPG 콘솔 게임

내일배움캠프 프로젝트로 진행한 **C# 콘솔 텍스트 RPG**입니다.  
MVC 패턴을 기반으로 플레이어 생성, 인벤토리 관리, 상점, 던전 등을 구현했습니다.

---

## ✅ 현재 구현된 기능

### 1. 📌 인트로 & 메인화면
- ASCII 아트로 타이틀 출력 (중앙 정렬)
- 사용자 데이터가 있으면 인트로 스킵
- 메인 선택지: 상태 확인, 인벤토리, 상점, 던전, 종료

---

### 2. 👤 플레이어
- 이름, 직업 선택
- 레벨, 경험치, 능력치(Status) 관리
- 장비 슬롯(무기, 방어구) 관리

---

### 3. 🗃️ 인벤토리 시스템
- 소지 아이템 확인
- 장비 착용/해제
- 착용 중인 아이템은 [E]로 표시
- 장비 스탯 표시
- 잘못된 입력 처리 (범위 벗어나면 안내 메시지)

---

### 4. 🛒 상점 시스템
- 아이템 구매
- 가진 돈보다 비싸면 구매 실패 → 경고 메시지 출력 후 다시 구매 화면으로 이동
- 이미 보유한 아이템은 구매 완료 표시 가능
- 구매 시 인벤토리에 추가, 돈 차감

---

### 5. ⚔️ 던전 시스템
- 던전 데이터(XML) 파싱 및 관리
- 권장 방어력 기반 클리어 확률 계산
  - 방어력 높으면 확정 클리어
  - 낮으면 40% 확률로 실패 가능
- 클리어 시 골드 및 아이템 보상 지급
- 보상은 DTO로 관리하여 UserController로 전달

---

### 6. 💾 저장 데이터 관리
- `SaveData` 클래스를 통해 XML로 저장
- 플레이어 정보: 이름, 직업, 레벨, 능력치, 인벤토리, 장착 장비, 돈
- XMLSerializer 사용
- 필요한 클래스는 parameterless 생성자 구현 및 프로퍼티 get;set; 구성

---

## 🔧 주요 설계
- **MVC 패턴**: View는 출력 전담, Controller는 로직 처리, Model은 데이터 관리
- **싱글톤 패턴**: InputManager 등 공용 리소스 관리
- **DTO 패턴**: 던전 보상, 상점 거래 시 데이터 전달
- **XML 리소스 관리**: 아이템/던전 데이터 외부 파일로 관리해 유지보수 용이

---

## ⚙️ 실행 방법
1. Visual Studio 또는 Rider로 프로젝트 열기
2. XML 파일 경로 확인
3. `Program.cs` 실행
